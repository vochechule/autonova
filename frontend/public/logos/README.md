# Loga značek aut

Tato složka obsahuje loga různých značek aut.

## Formát logů

- PNG formát
- Rozměry: 32x32px nebo 64x64px
- Průhledné pozadí
- Název souboru: `[key_značky].png` (např. `skoda.png`, `volkswagen.png`)
